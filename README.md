## What SourceLace does

AI assistants are only useful at work if they can reach the systems where the work happens: the CRM, the ERP, the data warehouse. Most companies are right to hesitate, because it is hard to control what an assistant can see and do.

SourceLace is an AI-native platform for enterprise systems. It lets people and AI agents ask questions of a company's business systems and act on the answers, live, without copying the data into a lake first. Each person signs in to each system with their own account wherever the system allows it, so that system's own permissions decide what they see. SourceLace adds what an enterprise needs before it lets AI near its data: access by group, rules that hide or mask sensitive values before the AI sees them, changes that wait for a person's approval, and a tamper-evident record of every call. It works with any AI model.

**The web app (https://sourcelace.ai).** People sign in, connect their systems, chat with an assistant that works with their own permissions, and build, run and approve AI agents. It also makes charts, Word, PowerPoint and PDF reports, and Excel and CSV files from results, supports voice, and gives admins pages for people, groups, connections, sign-in, data protection, limits, usage and the audit trail.

**Any AI app, through MCP.** Teams that prefer their own AI app can add SourceLace as one connector (MCP, the Model Context Protocol, is an open standard that lets AI assistants connect to tools and data). The same tools, the same permissions and the same protections apply.

**Connectors.** Salesforce, HubSpot, Microsoft Dynamics 365, Oracle NetSuite, Workday, ServiceNow, Zendesk, Jira, Snowflake, Google BigQuery, PostgreSQL, Google Drive, Gmail and more, with others such as SAP in pilot. Reads are read-only; changes are off until an admin turns them on, and every change is previewed and confirmed by a person before it is applied.

**AI agents.** Saved jobs that run on a schedule, when something happens in a connected system, or when a record meets a condition (a renewal date coming up, an order blocked too long). They run with their owner's permissions, draft emails and documents, and propose changes that wait for approval. Agents can run in a trial mode first, and ready-made templates, including industry packs, get teams started quickly.

**Governance and trust.** Access by group, data protection rules, approvals before changes, no standing copies of source data, and an audit trail admins can export. Sign-in works with Google, Microsoft or a company's own single sign-on.

SourceLace is sold as a hosted service (SaaS), so customers have nothing to install or run. Website: https://sourcelace.com
